Three ways to use this

  • Run it live in your browser (no install): open any lesson and click Run live ▶ — the real Python runs in your browser, so you can change a sample size, a seed, or a confidence level and re-run to watch the result change.
  • Just read it: click any lesson below to read the finished page — every chart already drawn, the math typeset, nothing to install.
  • Run it on your own computer: install Python, then pip install -r requirements.txt and open the lessons/ folder in JupyterLab.
  • Each lesson teaches on three levels: the math, what the number means, and what the result says about the world. Most lessons also offer the same idea on another dataset and a code-focused companion.

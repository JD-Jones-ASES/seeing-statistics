# Verified dataset catalog

**59 datasets** from reliable public sources, each checked to be real, free, and downloadable. They are mapped below to the statistics concepts they teach best. Every URL was visited during research; none were dropped as unreachable.

> Load any of these in a notebook with `statslab.load_csv('name.csv', url='...')` — it caches one copy into `raw/` and reuses it offline. Log new ones in `SOURCES.md`.

## Recommended "population" dataset (the simulation spine)

**Ames, Iowa Housing Sales 2006-2010**

It is a single clean CSV of ~2,930 complete rows — large enough that "the file IS the population" is convincing, yet small enough to load instantly and recompute on the fly. Gr.Liv.Area (above-grade living area, sq ft) is a genuinely continuous variable with no missing values, so the TRUE population mean is computable from the full file in one line. Critically for a simulation-first course, Gr.Liv.Area (and SalePrice) are mildly RIGHT-SKEWED, which makes it the ideal teaching population: students see firsthand that the sampling distribution of the mean still becomes normal (Central Limit Theorem) even when the underlying population is not, and the flagship "draw 100 samples, build a 95% CI from each, count how many cover the known true mean" coverage demo lands harder because the population is visibly non-normal. Alternatives like NHANES P_BMX are larger and have a prettier near-normal height variable, but missing values and the need to link a separate demographics file add friction to the "compute the true mean from one file" step; ACS PUMS is enormous but its survey weights make a naive "true mean" misleading. Ames hits the sweet spot of size, cleanliness, one-file convenience, and a pedagogically useful skewed shape.

## Known gaps (where the data is thin)

- Genuinely small-n paired/before-after designs are thin: only Swim Velocities (n=12), Textbooks (n=73), and Blood Serum cover paired tests, so instructors have limited variety for the paired-test unit.
- True experimental designs with random assignment are scarce — most datasets are observational, so the causal-inference framing behind hypothesis testing/power must lean on a couple of small lab studies (ToothGrowth, Blood Serum) or be taught conceptually.
- No dataset is purpose-built for statistical POWER and Type II error exploration (effect size vs sample size vs alpha); power must be demonstrated via simulation on the spine dataset rather than from a dataset designed for it.
- Binomial/Poisson count modeling is covered only indirectly (earthquakes, births, baseball); there is no clean small dataset of discrete trial outcomes (e.g., explicit successes/failures) tailored to first-principles binomial teaching.
- Confidence intervals for a proportion and chi-square goodness-of-fit (as opposed to independence) have limited dedicated, beginner-sized categorical datasets — most categorical work funnels through Titanic, risking over-reliance on a single example.
